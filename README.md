# SCIENCE FIELD

科学・化学・生物・実験・農業と環境をテーマにしたブログサイトの初期版です。

## 使い方
- `index.html` がトップページ
- `posts/example.html` が記事ページのサンプル
- `assets/style.css` がデザイン

## 公開
GitHub Pages / Cloudflare Pages / Netlify などの静的サイトホスティングにそのまま公開できます。

## 収益化
広告サービスの審査・利用規約を確認したうえで、広告コードを `ad-box` / `post-ad` 部分へ設置できます。
アフィリエイト記事では、広告・PRであることが分かる表示を入れてください。
